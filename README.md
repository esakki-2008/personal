# A Birthday Universe for Lavinia ✦

A cinematic, responsive birthday surprise built with React, TypeScript, Three.js / React Three Fiber, Drei, Framer Motion and GSAP.

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Experience

- A star-filled opening scene with a procedural 3D gift box.
- Birthday celebration, procedural cake and wish interaction.
- An envelope that opens to reveal a personal letter.
- A generated fantasy flower garden.
- Six interactive appreciation cards.
- An interactive crystal-heart surprise.
- A stylized animated fireworks finale.
- A replayable final birthday moment.
- Optional, user-initiated synthesized ambient sound (no external audio assets).

## Assets and performance

All illustrations and 3D objects are generated from CSS and Three.js geometries. No personal photographs, image placeholders, or third-party image URLs are used. The 3D canvas uses a capped device-pixel ratio and moderate particle counts; the layout includes a reduced-motion mode and responsive mobile styling.

Google Fonts are used for typography when online; system fallbacks remain available when offline.
